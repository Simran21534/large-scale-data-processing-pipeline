# Large-Scale Data Processing Pipeline

## Project Overview

A PySpark-based data engineering project that demonstrates data
processing, transformation, data-quality validation, Spark SQL
analytics, and Parquet-based data storage.

## Architecture

Raw Data
↓
PySpark
↓
Data Cleaning & Validation
↓
Transformations
↓
Spark SQL
↓
Analytics
↓
Parquet

## Data Quality

The pipeline validates:

- Missing values
- Invalid quantities
- Invalid prices
- Duplicate orders

## Business Analysis

The pipeline calculates:

- Total orders
- Units sold
- Total revenue
- Average order value
- Revenue by category

Built a PySpark data processing pipeline that transforms raw
